# Alexandra Enck — Portfolio

Static portfolio site for Alexandra Enck’s illustration, graphic design,
knitwear, and television work.

Live site: [alexandraenck.github.io](https://alexandraenck.github.io)

## Main files

- `index.html` — page content, SEO, and section structure
- `assets/css/styles.css` — colors, typography, layout, and responsive styles
- `assets/js/site.js` — galleries, lightbox, dialogs, video, and cursor behavior
- `assets/js/image-data.js` — responsive image paths and dimensions
- `assets/images/portfolio/` — unchanged original artwork
- `assets/images/portfolio-optimized/` — lightweight display copies

There is no build step. Edit the files directly and push `main`; GitHub Pages
publishes the static site automatically.

Artwork sources and handling notes are documented in
[`SOURCE-NOTES.md`](SOURCE-NOTES.md).
